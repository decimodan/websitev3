Dirigiendo el área de Cloud y Devops tuve oportunidad de crear algunas apis bancarias cómo:

- Pago a créditos con TDD
- Información de saldos
- Información de clientes
- Domicilios
- Llaves de seguridad

Usando Apigee como API Gateway, Kubernetes + Docker (Rancher) para poder montar los diferentes microservicios y Oracle como base de datos.

Link: [APIS](https://apifactory.apibaz.com/)
