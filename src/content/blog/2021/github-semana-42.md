## **[1) Bone](https://github.com/Merkoba/Bone)**

![Bone](/blog/bone.jpeg)
**Repo: [Link](https://github.com/Merkoba/Bone)**

Bone es una herramienta que te permite mostrar hasta 4 websites de 16 formas diferentes (todo en la misma pantalla). Lo que me gusta es que te los muestra sin todo los elementos que hacen que se vuelva extremadamente pesado, por lo que te permite tener un visor de muchas páginas de forma simple.

Algunas de sus características:

- Botones para cambiar y recargar websites
- Puedes configurar las proporciones de cada website
- Soporta presets

Entre muchas otras cosas. Puede ser util cuando revisas algunos websites de forma periódica o si quieres tener algún tipo de tablero liviano.

## [2) Omnino](https://github.com/bopwerks/omnino)

![Bone](/blog/omnino.png)

**Repo: [Link](https://github.com/bopwerks/omnino)**

Omnino es un sistema de ventanas para aplicaciones web ([inspirado en el editor de texto Acme](http://acme.cat-v.org/)). Divide la pantalla porciones y se pueden crear columnas que pueden cambiar de tamaño, reordenadas o eliminadas.

Además, se puede modificar su estilo con CSS, lo que permite que puedas agregarlo a tus aplicaciones web.

Puedes ver un demo [aquí](https://bopwerks.github.io/omnino/)

## 3) [Graphsignal](https://github.com/graphsignal/graphsignal)

Graphsignal es un herramienta que te permite monitorear tus modelos de Machine Learning, esto te ayuda a encontrar rápidamente problemas entre los datos y tus modelos lo que te permite mejorar el performance y la disponibilidad de tus modelos.

Algunas de sus características:

- Data Monitoring
- Model performance monitoring
- Automatic issue detection
- Model framework and deployment agnostic
- Any scale and data size
- Data Privacy

Puedes aprender más de todo esto [aquí](https://graphsignal.com/)
